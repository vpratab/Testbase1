# Transition Gate Checklist

The 95+ scores represent Phase I laboratory requirement match. These are the
remaining customer-owned proofs required before stronger operational or TRL
claims.

| Topic | External proof still required | Evidence package to request |
| --- | --- | --- |
| QSPARX | AFDW or sponsor-approved cyber-range access | endpoint population, CMDB export, network scan authorization, approved crypto policy |
| NV059 | Combat-system network fabric and DoD identity | CAC/PIV test identities, segmentation controller, DDS Security governance, representative protocol endpoints |
| NV061 | Operational multi-source composite tracks | de-identified track corpus, identity/custody truth, analyst priority dispositions |
| NV062 | Credentialed commercial collection tasking | provider sandbox credentials, task/order API agreement, return-data agreement, security boundary decision |
| NP002 | Live C-UAS field detection and payload labels | synchronized EO/RF/acoustic/radar recordings, target type and payload truth, clutter and weather metadata |
| NV063 | SSDS or representative composite-track interface | interface control document, replay corpus, operator alert disposition, air/surface anomaly truth |
| NV065 | Program-of-record sensor and SSDS constraints | approved sensor model, task-mode limits, beam/dwell conflicts, operator authorization workflow |

No laboratory artifact should be described as replacing these transition
inputs.
