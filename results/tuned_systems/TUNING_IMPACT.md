# Tuning Impact

The systems are now separated by mission semantics rather than by renamed
inputs. This improves architectural credibility and prevents cross-topic
overclaiming, but it does not erase external integration gaps.

## What changed

- QSPARX now treats cryptographic migration as a dependency-constrained mission
  plan, not merely an algorithm vulnerability list.
- NV059 now uses bounded offline trust leases and temporal misuse evidence for
  individual data actions.
- NV062 now uses purpose-bound, single-use task intent with separate delivery
  and return evidence.
- NP002 now reasons at the swarm-formation level and discounts conclusions when
  track custody is weak.
- NV061 now makes custody confidence an explicit factor in ranking rather than
  hiding identity uncertainty.
- NV063 now distinguishes watch alerts from high-confidence persistent
  deviations and explicitly avoids equating anomaly with hostility.
- NV065 now recommends task movement using conflict-adjusted marginal
  information value rather than generic threat scoring.

## Effect on the 1-100 scores

The empirical campaign scores remain the authoritative numbers. The extension
campaign adds measured OPC UA, OpenSky, active TLS, scaling, workflow, and
constraint evidence. The third wave additionally adds encrypted OPC UA,
Cyclone DDS, NASA acoustic recordings, live air forecasting, and a real
external STAC data return. The fourth wave adds a compartmented cryptographic
range, mTLS process-level microsegmentation, commercial SAR returns from
Capella and Umbra, acoustic-assisted track identity, an authenticated
composite-track contract, and a traceable radar-equation scheduler.
The fifth wave adds live migration execution, official provider task-schema
conformance, signed control evidence, grouped surface-track classification,
versioned composite tracks, and beam/revisit scheduling. Architecture tuning
alone still receives no points where the missing requirement is external:

- no AFDW environment
- no combat-system microsegmentation
- no commercial satellite provider
- no real C-UAS sensor data
- no SSDS composite tracks
- no program-of-record radar parameters

The tuning mainly strengthens technical coherence, evaluation plans, and the
credibility of Phase I execution. New measured score increases should only be
claimed after running the next external-data or integration experiments.
